# 🏋️ FITLOG - Workout & Fitness Tracker

FITLOG is a sleek, modern, dark-themed fitness companion built to help users browse curated exercises, configure daily lifting routines, and track total workout metrics seamlessly.

### ✨ Key Features

- **Curated Exercise Library:** 
  - Browse a comprehensive grid of exercises covering every major muscle group (Chest, Arms, Legs, Core, Shoulders, Full Body).
  - High-visibility category tags indicating targeted muscle groups and required equipment (Barbell, Bodyweight, Dumbbell, Kettlebell).

- **In-Depth Exercise Details:** 
  - Detailed modal/page view showcasing exercise difficulty, target sets, rep ranges, estimated duration, expected calorie burn, and community ratings.
  - Step-by-step numbered movement instructions to reinforce proper lifting form.
  - Quick action controls to add directly to "Today's Plan" or "Save for Later".

- **"My Plan" Daily Logger & Metric Tracker:**
  - Real-time aggregated summary dashboard calculating total exercises, aggregate training duration (minutes), and projected calorie burn.
  - Interactive lifting checklist with "Mark as Done" task completion toggles and quick-remove options.
  - Dynamic sort capabilities (e.g., sorting daily exercises by duration).

- **Saved Items & Plan Management:**
  - Dedicated "Saved" tab to bookmark movements for future routine design.
  - Persistent header navigation with real-time badges tracking active plan count and saved items.

- **Responsive & Immersive Dark UI:**
  - Built with a deep charcoal and neon-accented interface designed for high contrast and distraction-free gym floor use.
